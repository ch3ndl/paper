# 论文目录

这里是网站论文内容的唯一入口，每篇论文一个目录：

```text
library/
  deeploc-2/
    result.zip
    README.md
    taxonomy.txt
```

- 新增论文：上传 Skill 生成的论文目录，提交到 main。
- 更新正文或图片：替换对应目录里的 result.zip。
- 修改分类、移动到其他分类、增减标签：直接编辑 taxonomy.txt。
- 下架论文：删除整篇论文目录后提交。目录不再存在，网站就不再展示该论文。

不要将结果包解压到仓库其他位置。result.zip 包含 notes/<目录名>.json 和实际引用的图片，目录名须与包内 slug 相同。

分类只能有一条；用 / 表示多层级。标签可自定义多个，每行一个：

```text
分类: 生物信息学 / 蛋白质定位

标签:
- 蛋白语言模型
- 亚细胞定位
- 多标签分类
```

网站按 taxonomy.txt 覆盖结果包里原有的分类、标签。父分类会包含所有子分类文章，无须维护额外的分类总表。无标签时保留空的“标签:”栏目。

README.md 便于直接在 GitHub 阅读论文名、作者、简介和出处；正文来自 result.zip，分类标签来自 taxonomy.txt。

提交后 GitHub Actions 自动校验并发布。缺文件、重复分类、目录名不一致或结果包损坏会使构建失败，已上线版本保持原状。
