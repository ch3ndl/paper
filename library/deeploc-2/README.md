# DeepLoc 2.0：从蛋白质序列到多标签亚细胞定位

DeepLoc 2.0: multi-label subcellular localization prediction using protein language models

- **作者**：Vineet Thumuluri；José Juan Almagro Armenteros；Alexander Rosenberg Johansen；Henrik Nielsen；Ole Winther
- **发表年份**：2022
- **原文链接**：https://doi.org/10.1093/nar/gkac278
- **文献出处**：Thumuluri V, Almagro Armenteros JJ, Johansen AR, Nielsen H, Winther O. Nucleic Acids Research, 2022, 50(W1): W228–W234. DOI: 10.1093/nar/gkac278.
- **最后整理**：2026-11-11

## 简介

DeepLoc 2.0 将预训练蛋白质语言模型与多标签预测结合，仅用序列预测多个亚细胞定位，并通过注意力和分选信号预测提供辅助解释线索。
