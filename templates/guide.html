READ · THINK · KEEP

在 GitHub 整理，在这里阅读。

网站用于浏览和精读论文。每段左侧展示五色标注的英文原文及米色背景的中文译文，右侧给出段落功能、逻辑角色、论证技巧或潜在漏洞，以及详细讲解。手机上按英文、译文、批注的顺序阅读。

一篇论文，一个目录

所有文章都放在 GitHub 仓库的 library 目录，每篇论文有自己的子目录。例如 library/deeploc-2/，里面包含以下文件：

result.zip：完整阅读结果包，包含结构化笔记、独立 HTML 和论文图片。

README.md：论文名、作者、发表年份、简介、原文链接和阅读范围，方便直接在 GitHub 查看。

taxonomy.txt：一条分类路径和多个自定义标签，是网站分类标签的唯一依据。

上传、修改和删除

  1. 使用 paper-library-note Skill 整理论文，取得论文目录。
  2. 把整个论文目录上传到仓库 library 下，提交到 main。
  3. 更新正文或图片时，替换该目录里的 result.zip；编辑 README 可维护简明介绍。
  4. 修改分类或标签时，只需编辑 taxonomy.txt。
  5. 下架文章时，删除整篇论文目录并提交。

提交后自动构建、校验并发布。可在 GitHub Actions 查看进度。格式错误不会替换已上线版本。

一条分类路径，多个标签

每篇文章只能属于一个分类；分类可以包含任意多层，用斜杠分开。例如“生物信息学 / 蛋白质定位 / 深度学习”。首页选择父分类时，会包含其全部子分类文章。

分类: 生物信息学 / 蛋白质定位

标签:
- 蛋白语言模型
- 亚细胞定位
- 多标签分类

标签逐行填写，可以自由命名和增删；没有标签时保留空的“标签:”栏目。不要重复添加分类行。分类和标签由该文件管理，无须重新生成论文结果包。

来源与阅读边界

英文原文、中文译文和 AI 讲解分别标明。论文图片保存在论文结果包中，并随 GitHub 仓库存储；页面使用本站图片路径。未取得的图像或未核对的补充材料在文章中明确注明。

收藏仅保存在当前浏览器，不会同步到 GitHub。站点没有在线写入或授权令牌表单，论文内容通过 GitHub 修改。
