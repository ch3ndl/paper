READ · THINK · KEEP

一篇笔记，留下完整的阅读路径。

本站用于收集和发布 Saline 的论文阅读笔记。正文沿着原文章节顺序展开，阅读批注独立放在右侧；窄屏时批注跟在对应段落后面。每篇文章都有原文链接、阅读范围与核对状态。

先读懂作者做了什么

按原文结构解释研究背景、方法、逐项结果和讨论。关键数字要连同比较条件、图表编号与统计口径一起理解。

再判断证据支持什么

批注区标明 AI 分析，区分作者解释和读者判断。英文改写不会冒充原文摘录，未读补充材料也不会标成已核实。

用 Skill 整理论文

使用 paper-library-note Skill，提供论文 PDF、全文链接或正文，说明想归入的分类和标签。Skill 输出一个 ZIP 文件包，里面包含一篇 JSON 笔记和实际下载的论文图片。

上传、修改和分类

  1. 打开管理页面，连接 GitHub 仓库。
  2. 导入 Skill 导出的 ZIP 或 JSON；ZIP 会同时导入图片。单独导入 JSON 时，可在下方补充图片。
  3. 修改标题、分类、逗号分隔的标签、正文与批注。分类和标签会自动出现在论文库筛选中。
  4. 预览后点击“保存并发布”。文件先保存到 GitHub，随后由 GitHub Actions 构建更新，通常需要等待片刻。

编辑已有文章时，在左侧选择文章即可。已经发表的文章标识固定，以保持旧链接可用。导出 JSON 可备份正文；图片文件请同时保留。

管理页的 GitHub 授权

GitHub Pages 没有私有服务器，管理页通过 GitHub API 保存内容。首次使用需要创建一个只对 ch3ndl/paper 生效的 fine-grained personal access token：Resource owner 选 ch3ndl，Repository access 选 Only select repositories → paper，Repository permissions 中 Contents 选 Read and write。设置合理到期日，其他权限保持默认。

将令牌粘贴到管理页的密码框后点击连接。令牌只保留在当前页面内存中，仅向 api.github.com 发送；不会写入仓库、浏览器长期存储或笔记文件。用完可断开连接。公开访客没有令牌时只能查看网站，无法修改仓库。

也可以直接通过 GitHub 发布

把文件包中的 notes/<slug>.json 和 assets/images/<slug>/ 上传到仓库同名目录并提交。自动发布会检查格式、图片路径和来源信息。若构建失败，原有网站仍保持在线，在仓库 Actions 中可查看具体原因。

图片、来源与阅读范围

论文图片保存在同一 GitHub 仓库，使用本站路径展示。图注保留图号、原文链接与许可；不确定能否再发布的图片应先留缺口说明。本站第一篇 DeepLoc 2.0 来自用户提供的旧模板，明确标记为待核对：它展示迁移后的阅读样式，不代表已按原论文完整重新精读。

自定义域名

默认地址为 ch3ndl.github.io/paper/。要启用 paper.saline.cyou，先在仓库 Settings → Pages 设置 Custom domain 为 paper.saline.cyou，再在 Cloudflare 添加 CNAME：名称 paper，目标 ch3ndl.github.io（不含 /paper），初次配置可使用 DNS only。等待 DNS 与证书就绪后开启 Enforce HTTPS。
